# 🍇 Calcuberry 🍇

**Calcuberry** is a cute but fierce scientific calculator built using HTML, CSS, and JavaScript.  
It’s fully functional, totally purple, and slightly dramatic — just like your math grades after using it.

## 🔮 Features

- 🎨 Aesthetic: Custom purple-core theme (yes, it's giving amethyst)
- 🔢 Functions:
  - Basic: `+`, `-`, `*`, `/`, `%`, `C`, `DEL`
  - Advanced: `π`, `e`, `^`, `√`, `x²`, `log`, `ln`, `exp`, `abs`, `1/x`, `+/-`, parentheses
- 🧠 Smart Logic:
  - Safe input validation (no exploding `eval()`s here)
  - Supports all expressions with auto-multiplication
  - Handles parenthesis mismatch, zero division, and log/√ of negatives
- 📱 Mobile-friendly & responsive
- 🎯 Instant results, no reloads or forms
